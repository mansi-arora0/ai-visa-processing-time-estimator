## Internship Artifacts

This folder contains all Agile and QA documentation created and maintained
throughout the project lifecycle for the **AI Visa Processing Time Estimator**.

### Included Documents
- **Agile_Template_v0.1.xlsx**  
  User stories planned and tracked across all milestones (Sprint 1–4),
  following Agile and MoSCoW prioritization.

- **Defect_Tracker_Template_v0.1.xlsx**  
  Bugs identified during development, including data mismatches,
  UI issues, and logic errors, along with resolution details.

- **Unit_Test_Plan_v0.1.xlsx**  
  Functional test cases validating model training, prediction flow,
  database persistence, visualizations, and reset behavior.

These artifacts ensure transparency, traceability, and quality assurance.
