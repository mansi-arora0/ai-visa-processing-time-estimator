# Raw Data Information

The raw datasets used in this project are publicly available from the
U.S. Citizenship and Immigration Services (USCIS) Immigration and Citizenship
Data Library.

## Data Source
- Website: https://www.uscis.gov/tools/reports-and-studies/immigration-and-citizenship-data
- Dataset: Appropriations Reporting Requirement – Application Processing Data
- Format: Monthly CSV files
- Time Period: 2024–2025

## Notes
- Raw CSV files are not included in this repository to keep it lightweight.
- All raw files can be downloaded directly from the USCIS website.
- The preprocessing steps to clean and merge these files are implemented in `preprocessing.py`.

## Files Expected in This Folder
Example filenames:
- appropriation_requirement_january_2024.csv
- appropriation_requirement_april_2025.csv
- appropriation_requirement_july_2025.csv
